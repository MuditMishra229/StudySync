# StudySync – Student Study Planner

Developed by: ByteBuilders

## About
StudySync is a student productivity website designed to help students organize academic tasks, plan weekly study sessions, and track their progress.

## Features
- Add, edit and delete academic tasks.
- Set deadlines and priorities.
- Mark tasks as completed.
- Weekly study planner.
- 12-hour time display (AM/PM).
- Productivity statistics.
- Circular progress tracker.
- Subject-wise progress.
- Upcoming deadlines.
- Responsive layout.

## Technologies Used
- HTML
- CSS
- JavaScript
- Browser Local Storage

## How to Run
1. Extract the ZIP folder.
2. Open the StudySync folder.
3. Double-click index.html.
4. The website opens in your browser.
